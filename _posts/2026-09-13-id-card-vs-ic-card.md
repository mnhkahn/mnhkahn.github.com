# ID卡和IC卡怎么区分

门禁卡、考勤卡和停车卡常被统称为“感应卡”，但其中最常见的 ID 卡和 IC 卡在原理、能力与使用方式上并不相同。日常想快速判断手上的卡属于哪一类，通常只需看卡面编号，再用手机 NFC 试一下即可。

> 本文讨论的是常见的非接触式卡。使用、备份或管理门禁凭证前，应取得发卡方或场所管理方授权；不要将相关工具用于未经授权的访问。

# 本质区别：频率与读写能力

ID 卡（身份识别卡）通常是 125 kHz 的低频卡。芯片内一般固化有唯一序列号（UID），读卡器读取卡号后再与后台数据库比对完成身份验证。常见 ID 卡仅用于提供卡号，通常不能由用户写入数据，也不具备强加密能力。

IC 卡（集成电路卡）通常工作在 13.56 MHz 高频段，属于带集成电路的智能卡或存储卡。它们往往支持分区读写、访问控制与不同程度的加密。常见类型包括 MIFARE Classic（M1 卡）和 NTAG 系列。

手机 NFC 也使用 13.56 MHz，因此能与符合相应标准的高频卡通信；它不能直接读取 125 kHz 的低频 ID 卡。这是区分两类卡最直观的物理依据之一。

| 对比项 | ID 卡 | IC 卡 |
| --- | --- | --- |
| 全称 | 身份识别卡（Identification Card） | 集成电路卡（Integrated Circuit Card） |
| 常见工作频率 | 125 kHz（低频） | 13.56 MHz（高频） |
| 读写能力 | 通常仅提供固化 UID | 通常可读写，可能支持访问控制或加密 |
| 常见芯片 | EM4100、TK4100 | MIFARE Classic（M1）、NTAG213/215/216 |
| 手机 NFC 能否感应 | 不能 | 通常可以 |
| 安全性 | 较低，卡号通常可直接读取 | 因芯片和配置而异，可使用加密 |
| 典型应用 | 老旧门禁、考勤、停车场 | 一卡通、公交卡、新式门禁、NFC 标签 |

# 五种区分方法

## 方法一：看卡面数字

这是最快、也不需要任何工具的方式。许多 ID 卡的卡面印有一串以 `00` 开头的数字：钥匙扣卡常见为 8 位或 10 位，例如 `00123647`、`0098764736`；部分标准白卡还会印更长的十进制编号。这通常是芯片 UID 的十进制表达或厂商编号。

IC 卡卡面则常常没有这类 `00` 开头的编号。不过，部门自行印制的资产号、工号并不能作为判断依据，因此这一步只能作初筛。

## 方法二：用手机 NFC 试一下

打开手机 NFC 功能，把卡贴近手机背部的 NFC 感应区（通常在摄像头附近）并缓慢移动。

- 有震动、提示音或系统提示：通常说明手机检测到 13.56 MHz 的 IC 卡或 NFC 标签。
- 完全没有反应：可能是 125 kHz 的 ID 卡；也可能是手机 NFC 未开启、感应位置不对，或该高频卡不被手机支持。

因此，NFC 有反应是判断高频卡的强信号；无反应时，建议再结合卡面和读卡器确认。

## 方法三：用手电筒观察线圈

在较暗环境中，用手机手电筒从卡片背面贴近照射，有时能看见内部天线线圈。

- ID 卡的低频线圈通常匝数更多、线距较大，外形常偏圆或椭圆。
- IC 卡的高频线圈通常匝数较少、线距较细，外形常偏方形。

不同厂商的封装和定制天线会有差异，深色印刷卡也可能看不清线圈，所以这是一种辅助判断方法。

## 方法四：看厚薄和手感

低频 ID 钥匙扣经常显得更厚、更鼓；高频 IC 钥匙扣通常能做得更薄、更平整。这与天线设计和封装有关，但不同产品的差别很大，不能据此下定论。

## 方法五：用专业工具确认

需要准确识别芯片型号、协议或加密状态时，专业工具最可靠：

- **Proxmark3（PM3）**：覆盖 125 kHz 与 13.56 MHz 常见协议，可分别通过 `lf search` 和 `hf search` 检测低频、高频卡。
- **NFC Tools**：手机应用，仅能处理 13.56 MHz 卡；可显示 UID、技术类型，例如 NfcA、MIFARE Classic、NTAG。
- **MIFARE Classic Tool（MCT）**：面向 MIFARE Classic 卡，可在已获授权的情况下读取扇区、验证密钥和备份数据。
- **125 kHz 单频读卡器**：专门读取 ID 卡号，适合只需确认低频卡号的场景。

# 特殊卡种：UID、CUID、FUID 与 UFUID

高频 IC 卡市场中还存在一些俗称“魔术卡”的兼容卡。它们的共同特点是 UID 所在区域的可写规则与正规原厂卡不同，常见名称包括 UID 卡（Gen1A）、CUID 卡（Gen2）、FUID 卡和 UFUID 卡。

| 类型 | 一般特性 |
| --- | --- |
| UID 卡（Gen1A） | UID 区域通常可重复修改，常用于兼容性测试。 |
| CUID 卡（Gen2） | 常见实现支持反复修改 UID，但不同批次和厂商的行为可能不同。 |
| FUID 卡 | UID 通常只能写入一次。 |
| UFUID 卡 | 通常支持写入后锁定；锁定后不能再修改。 |

卡面印着 “CUID” 只是商业标称，不能保证具体实现或兼容性。若需要确认卡片行为，应在合法授权的测试环境中使用兼容工具实际验证，而不要仅凭印字判断。

# 知道类型后能做什么

- **ID 卡**：通常只能读取卡号；手机 NFC 无法操作这类 125 kHz 卡。
- **IC 卡**：手机可以识别部分高频卡，但是否能读取内容、写入数据或作为凭证使用，取决于芯片型号、密钥、手机硬件和发卡方设置。
- **CPU 卡**：一般使用更强的安全机制；应通过发行方提供的正规渠道进行管理或补卡。
- **写入网址或文本**：优先选择 NTAG213、NTAG215、NTAG216 等标准 NFC 标签，适合写入 NDEF 格式的链接、文本和名片。MIFARE Classic 更常见于门禁或存储分区场景，NDEF 兼容性并不如专用标签稳定。

# 总结：日常判断三步走

| 步骤 | 操作 | 判断 |
| --- | --- | --- |
| 第一步 | 看是否有 `00` 开头的长编号 | 有则更像 ID 卡，但仍需交叉验证 |
| 第二步 | 用手机 NFC 感应 | 有反应通常是 IC 卡；没反应则可能是 ID 卡 |
| 第三步（可选） | 用手电筒观察线圈 | 粗、多、偏圆更像 ID 卡；细、少、偏方更像 IC 卡 |

对大多数日常场景来说，“看数字 + 手机 NFC 感应”已经足够实用。只有在需要确定芯片型号、协议或访问控制状态时，才需要使用 Proxmark3、NFC Tools 等工具进一步确认。
